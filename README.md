# Ameya Parab — Laser–Plasma Physics

Personal research portfolio of Ameya Parab, PhD research scholar at TIFR.

Website: https://photoscopic.github.io/

Static HTML, CSS and JavaScript, hosted through GitHub Pages from the main branch. Edit index.html for biography and research content, app.js for publications, and style.css for appearance. The website presents the introduction, research overview, qualifications, research work, publications, schools and presentations, Optica leadership, and personal interests in separate sections.
